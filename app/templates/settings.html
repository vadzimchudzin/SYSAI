Разметка голосов

Как узнавать одного и того же человека по всей записи. Запись расшифровывается кусками по 45–90 секунд, и каждый кусок размечает голоса заново — «Спикер 2» одного куска надо узнать в следующем. Образцы голосов сотрудников для этого не нужны: голоса сравниваются внутри одной записи. Способы сравниваются на эталонах — Точность разметки голосов.

    {% for key, hint in diarization_hints.items() %}
  • {{ diarization_methods[key] }} — {{ hint }}{% if diarization_unavailable[key] %}{{ diarization_unavailable[key] }}{% endif %}
    • {% endfor %}

От 0,2 до 0,95. Выше — голоса реже объединяются в одного человека (больше лишних голосов), ниже — чаще (больше склеек). Лучший порог показывает сравнение на эталонах.

{% if voice_service %}Сервис голосов подключён{% else %}Сервис голосов не подключён задайте на сервере (Render → Environment) SYSAI_VOICE_SERVICE_URL и SYSAI_VOICE_SERVICE_TOKEN.{% endif %}

Если выбранный способ не сработал на записи (сервис недоступен, ошибка модели), остаются метки кусков — расшифровка не теряется, а на странице совещания написано, что случилось.

Имя ставится, только если разговор доказывает его не меньше чем на столько: человек представился (85%), ответил, когда его назвали по имени (60% за раз), это подтвердил ИИ. Ниже — «Спикер N» остаётся, а «Кто это?» на странице совещания предлагает 2–3 кандидата с причинами и фрагментами, чтобы прослушать.

Хранилище записей

Записи совещаний хранятся в приватном S3-совместимом хранилище (Cloudflare R2, Yandex Object Storage, Selectel…): на диаграмме «Кто и когда говорил» их можно слушать с любого места и скачать. В хранилище уходит сжатая копия для речи — MP3, моно, 32 кбит/с, около 14 МБ на час. Копия удаляется через {{ retention_days }} дней, а вместе с совещанием или по кнопке «Удалить запись» — сразу.

Импорт TicNote через Notion

TicNote должен экспортировать транскрипт в выбранную страницу или базу Notion. SYSAI импортирует только страницы внутри указанной области и запускает существующий анализ. Это импорт текста: оригинальный WAV и повторная акустическая диаризация здесь не передаются.

Создайте отдельную страницу или базу для экспорта TicNote и укажите её здесь. Сохраните настройки, чтобы разрешить импорт только из этой области.
