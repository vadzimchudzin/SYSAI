# hub/seed/ — первые навыки SYSAI_Hub

Папки навыков в формате SKILL.md (`name`, `description`, `version`; «Когда применять», «Как делать», «Ошибки»,
«Проверка») + `references/`, `scripts/`, `assets/`. Загружаются в SYSAI_Hub архивом (страница «SYSAI_Hub»), проходят
проверку и публикуются владельцем. Первые навыки ОПО появятся вместе с plc-kit (этап 13).

## Инструменты

- `ebpro-cmtp/` (1.6.0) — MCP-сервер для проектов Weintek EasyBuilder Pro (`.cmtp`/`.emtp`) без EasyBuilder:
  окна и объекты (виды, рамки, подписи, теги), меню (`cmtp_links`: какая кнопка какое окно открывает), таблица
  тегов OPC UA, картинки; PNG окна как на панели (`cmtp_render`), проверка (`cmtp_check`); правки в новый файл —
  тексты любой длины, сдвиг, размер, теги, имена окон, копии и удаление окон и объектов, кнопки на окна, новые
  теги OPC UA, окна и объекты из проекта-донора (с картинками, тегами и переходами); замок на файл для нескольких
  агентов и холста окна «Агент SYSAI».
- `ebpro-gui/` (1.0.0, Windows) — MCP-сервер: агент ведёт настоящий EasyBuilder Pro мышью и клавиатурой —
  открывает проект, снимает окна (PNG), нажимает, печатает, заполняет диалоги, ждёт окна; один ведущий за раз;
  окна загрузки в панель, паролей и прошивки — только человеку.

- `plc-kit/` (1.3.0) — MCP-сервер для программы ПЛК Schneider Machine Expert / CODESYS на ST без Machine Expert:
  читает `.export` и PLCopen XML (программы, блоки, списки переменных, задачи), таблица переменных с адресами и
  регистрами Modbus, карта адресов и пересечения, теги для панели (`plc_hmi_tags`), проверка текста (`plc_check`),
  стиль проекта (`plc_style`), проект как папка файлов `.st` и сборка в PLCopen XML для импорта (`plc_build`);
  связь панели и контроллера по моделям из ТЗ (`plc_link`: OPC UA или Modbus), теги OPC UA, этапы проекта
  (`plc_stage_update`); файл `.project` Machine Expert: чтение любого (и с проверкой целостности), новый проект из
  папки ST и шаблона с контроллером (`plc_project_build`, `plc_project_template`), каналы ввода-вывода
  (`plc_io`, `plc_io_map`).
- `machine-expert/` (0.1.1, Windows) — MCP-сервер: ведёт EcoStruxure Machine Expert его скриптовым интерфейсом —
  компиляция с ошибками компилятора по файлу и строке (`me_build`, `me_update`), `.project` по модели контроллера
  без шаблона (`me_create`), программа из `.project` с паролем (`me_export`), контроллеры в сети, симуляция,
  загрузка, чтение и запись переменных (`me_online`). Сам файл `.project` читает и пишет plc-kit.
  На живом Machine Expert не проверен; разбор формата и план проверки — `docs/opo/MACHINE_EXPERT.md`.
- `pic-index/` (1.0.0) — MCP-сервер: индекс библиотеки картинок оборудования (`pic-index.json` рядом с
  картинками): оборудование, состояние, вид, наборы по состояниям; поиск по смыслу на русском и латинице
  (`pics_find`), подписи вручную, проверка наборов.
- `doc-kit/` (1.0.0) — MCP-сервер: документация в Word по образцу — структура и оформление образца
  (`doc_outline`, `doc_text`), Markdown → .docx с титулом, оглавлением, рисунками и таблицами (`doc_export`),
  сверка с образцом (`doc_check`).

Загрузить архивом папки → проверка → опубликовать.

## Навык проекта под ключ

- `plc-project/` (2.2.0) — раздел «Проекты» окна «Агент SYSAI»: проект с нуля по этапам — материалы, решения
  (контроллер, панель, связь), программа на ST (plc-kit), проект и компиляция в Machine Expert (machine-expert),
  экраны (ebpro-cmtp, pic-index), предложение документации; разбор готового проекта (ПЛК + экраны) в стиль.
- `project-docs/` (1.0.0) — руководство пользователя и технический паспорт по образцу компании (doc-kit) из
  материалов, программы и экранов проекта.

## Навыки EasyBuilder Pro

- `ebpro-mnemoscheme/` (1.0.0) — отдельное умение собирать редактируемые мнемосхемы из объектов оборудования по схемам и ТЗ; статусы, переходы, проверка и безопасная сдача.

- `ebpro-project/` — проект целиком по материалам (теги ПЛК, схемы, ТЗ, примеры): три режима (файл, EasyBuilder,
  холст), план окон и меню, сборка, проверка, сдача черновика.
- `ebpro-donor/` — окна, меню и объекты из проекта-донора: версия, `map_tags` / `map_windows` / `map_devices`.
- `ebpro-team/` — несколько агентов: раздача окон и номеров, свои копии, сведение ведущим, варианты, холст,
  очередь к одному EasyBuilder.
- `ebpro-easybuilder/` — работа в самом EasyBuilder через ebpro-gui: цикл «картинка — нажатие — картинка»,
  диалоги, сохранение, компиляция, симуляция.
