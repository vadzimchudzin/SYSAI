# hub/seed/ — первые навыки SYSAI_Hub

Папки навыков в формате SKILL.md (`name`, `description`, `version`; «Когда применять», «Как делать», «Ошибки»,
«Проверка») + `references/`, `scripts/`, `assets/`. Загружаются в SYSAI_Hub архивом (страница «SYSAI_Hub»), проходят
проверку и публикуются владельцем. Первые навыки ОПО появятся вместе с plc-kit (этап 13).
