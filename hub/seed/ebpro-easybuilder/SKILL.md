# Работа в EasyBuilder Pro (мышь и клавиатура)

Нужен инструмент **ebpro-gui** на ПК с Windows и EasyBuilder Pro; для правок файла до и после — **ebpro-cmtp**.
ПК должен быть разблокирован; первые запуски — при человеке у экрана.

## Когда применять

- Нужен новый вид объекта, свойство в диалоге объекта, настройка проекта (System Parameters, устройства, шрифты,
  языки) — то, чего нет в правках `cmtp_edit`.
- Проверить собранный файл в EasyBuilder: открывается ли, как выглядят окна, компилируется ли.
- Офлайн-симуляция: показать человеку, как экран работает.

Если правку умеет `cmtp_edit` — делать ей: быстрее и без экрана.

## Как делать

1. **Открыть копию.** Сначала все файловые правки (ebpro-cmtp), потом `eb_edit` `{path: <выходной файл>}` — не
   исходник. Дождаться главного окна (ответ `eb_edit`, иначе `eb_windows`).
2. **Цикл** на каждый шаг: `eb_shot` (большой экран — сначала `scale: 0.5` для обзора, для точного нажатия —
   `scale: 1`) → найти на картинке место → `eb_click` / `eb_keys` / `eb_write` с `shot: true` → по картинке
   убедиться, что вышло. Больше двух-трёх действий без новой картинки не делать: диалог мог не открыться, фокус —
   уйти. `who` — всегда одно и то же имя.
3. **Окно проекта.** Дерево окон — слева в главном окне: двойной щелчок по имени окна открывает его на рабочем поле.
   Объект — двойной щелчок по нему на рабочем поле: откроется диалог свойств.
4. **Диалоги.** `eb_wait` `{title}` → `eb_controls` (поля, флажки, списки с номерами и местами) → `eb_write`
   `{control, text}` для полей → «OK» — `eb_click` в середину кнопки (x + width/2, y + height/2 из
   `eb_controls`) или `eb_keys` «enter». Вкладки и списки, которых нет в `eb_controls`, — по картинке.
5. **Лента** (вкладки сверху): по картинке; `eb_keys` «alt» показывает подсказки букв — следующая картинка скажет,
   какие нажимать.
6. **Сохранить** — `eb_keys` «ctrl+s», картинка: нет ли вопроса. «Сохранить как» — в диалоге файла `eb_controls`,
   `eb_write` полного пути в поле имени файла (SYSAI проверит, что папка открыта на запись) и «enter».
7. **Компиляция** — на ленте проекта кнопка компиляции (по картинке) → `eb_wait` окна компиляции → картинка
   итога: число ошибок и предупреждений → закрыть. Ошибки — выписать текст с картинки.
8. **Симуляция** — кнопка офлайн-симуляции на ленте → окно симулятора (`eb_windows`) → картинки нужных экранов
   (нажимать по экрану симулятора можно так же) → `eb_close` симулятора.
9. **Конец.** Сохранить, `eb_free`. Закрывать EasyBuilder, только если открывал сам и человек не работает в нём.
   После сохранения в EasyBuilder файловые инструменты читают файл заново: номера объектов могли измениться —
   перечитать `cmtp_windows` / `cmtp_objects` перед новыми `cmtp_edit`.

## Правила

- Загрузка в панель (Download), выгрузка, пароли, прошивка — только человек (ebpro-gui такие окна не трогает).
- Только окна EasyBuilder; не открывать другие программы и не трогать рабочий стол.
- Не нажимать «Да/Нет» в незнакомом вопросе вслепую: прочитать по картинке, при сомнении — спросить человека.
- Человек начал двигать мышь — остановиться, `eb_free`, спросить, продолжать ли.
- Пока ведёшь EasyBuilder, другие агенты его не трогают; закончил — `eb_free`.

## Ошибки

- «EasyBuilder сейчас ведёт …» — ведёт другой агент: ждать или работать с файлом.
- «не вышел на передний план» / «Windows не принял нажатия» — ПК заблокирован или EasyBuilder запущен от
  администратора: попросить человека.
- «точка вне окна» — координаты брать с картинки того же окна; при `scale: 0.5` — умножить на 2.
- Диалог не появился за время `eb_wait` — свежая картинка: может, открылось другое окно или нужен ещё щелчок.
- EasyBuilder спрашивает про версию или конвертацию проекта — не соглашаться без человека: файл собран под свою
  версию.
- EasyBuilder упал или завис — картинка, отчёт человеку; файл восстановить из последнего `out_file` ebpro-cmtp.

## Проверка

- После сохранения: `cmtp_info` файла читается, `cmtp_check` без ошибок.
- Компиляция без ошибок (картинка итога компиляции — в отчёт, `eb_shot` `out_file`).
- Изменённые окна — картинки из EasyBuilder (или симулятора) рядом с `cmtp_render`.
- В отчёте: что сделано в EasyBuilder по шагам, что не вышло и осталось человеку.
