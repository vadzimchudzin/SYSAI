# Схемы и чертежи в PDF

Схема Э3 линии — 40–90 листов А3. Показанная модели картинками, она стоит сотни тысяч токенов, а мелкие подписи
читаются с ошибками. У схемы, выгруженной из CAD в PDF, есть слой текста: инструмент читает его сам, без модели, —
слова каждого листа с местами, — и отвечает на вопросы компактными строками. Лист уходит в ответ как 1–3 КБ текста.

## Когда применять

- Этап «материалы» проекта: что есть в `materials/` (`draw_sheets` с `dir`), какие механизмы на схеме
  (`draw_devices` с `mechanisms: true`) — по этому перечню считают `expected` спецификации (`plc_spec_check`).
- Расставить сигналы по каналам: `draw_channels` — канал, устройство в его колонке, подпись.
- Найти, где нарисовано устройство или марка: `draw_find`.
- Прочитать перечень оборудования технологической схемы или спецификацию: `draw_table`.
- Посмотреть слова одного листа или его части: `draw_text`.

## Как запускать

Синхронизатор ставит папку в `%SYSAI_HOME%\tools\drawing-kit`, ставит зависимость из `requirements.txt`
(`pypdfium2` — чтение PDF, лицензия BSD-3 / Apache-2.0; своё окружение через `uv`) и запускает `python server.py`.
Прочитанный файл кэшируется по sha256 во временной папке: второй вопрос к той же схеме — мгновенный.

## Что умеет

| Инструмент | Что делает |
|---|---|
| `draw_sheets` | листы файла: название, сколько текста, устройства по видам, номера механизмов, модули, каналы; `dir` — PDF папки |
| `draw_devices` | обозначения без повторов с листами; `kind`, `mechanism`; `mechanisms: true` — перечень механизмов |
| `draw_channels` | каналы контроллера: модуль, устройство в колонке канала, подпись колонки |
| `draw_find` | где написано: лист, zone, фраза, что рядом; по файлу или по папке |
| `draw_text` | слова листа строками; `zone` 0–9 или `area` |
| `draw_table` | лист-таблица строками и ячейками |

Место на листе — номер листа и `zone`: колонка 0–9 рамки (цифры вдоль верхнего края листа А3). Координаты — пункты
(1/72 дюйма) от левого верхнего угла.

Обозначения читаются по ГОСТ 2.710, как на схемах заказчика: число перед буквами — номер механизма (`10KM1` —
контактор механизма 10), буквы — вид (`M` двигатель, `KM` контактор, `QF` автомат, `UZ` преобразователь частоты, `SQ`
датчик положения, `SR` датчик скорости, `SL` уровня, `SB` кнопка, `SA` переключатель, `HL` лампа, `HA` сирена, `K` реле,
`X` клеммник…). Кириллические «К», «М», «Х» в обозначении — те же буквы.

## Ограничения

- Только PDF со слоем текста. Скан (лист с `scan: true`) инструмент не читает: такой лист — на распознавание или
  модели, вырезкой нужного места.
- DWG, DXF, E3 — сначала в PDF (или инструмент `cad`).
- `draw_channels` связывает канал с устройством по расположению на листе: ближайшее в колонке канала. Это догадка —
  `distance` говорит, насколько далеко; канал без `device` или с большим `distance` проверяют по листу.
- Два обозначения, стоящие вплотную, могут прочитаться как одно («14» и «1K8» → «141K8»): номер механизма без
  двигателя (`drive: false`) — повод посмотреть лист.
- Линии и условные знаки не читаются: какой контакт нормально замкнут, что с чем соединено — по листу.
- Некоторые CAD пишут кириллицу в PDF с испорченной кодировкой — инструмент её восстанавливает; если на листе вместо
  русских слов остались значки, скажите об этом.

## Ошибки

- «нет библиотеки pypdfium2» — зависимость не поставилась: обновите инструмент в Хабе (нужен `uv` на ПК).
- «PDF не читается» — файл повреждён или защищён паролем.
- «нужен PDF» — дан другой формат.
