# EasyBuilder Pro: проекты .cmtp / .emtp

Формат разобран по EasyBuilder Pro 6.10.02.300 (подпись WEINTEK LABS, INC.). Контейнер:
`u32 revision` + версия (строка MFC) + второе слово revision; у новых версий (revision ≥ 240)
дальше `u32 длина` и тело в AES-128-ECB, у старых — открытым текстом. Пересборка байт-в-байт
проверена на всех 48 проектах из комплекта EasyBuilder.

Внутри — архив MFC: окна по номерам (у каждого номера свой слот; пустой номер — 4 нулевых байта, поэтому номер
окна — не просто его порядок в файле), в окне — объекты (CPartObject — виджеты, CDrawObject — фигуры). Разбор сверен
на реальном проекте cMT (88 окон, 2517 объектов, номера окон совпали с EasyBuilder); замена текста, сдвиг,
перепривязка тегов и имена окон проверены в EasyBuilder 6.10; копии окон и объектов сверены побайтно с копиями,
которые делает сам EasyBuilder (отличия — только GUID и служебные поля, которые он пересчитывает сам).

## Когда применять

- Разобрать присланный пример проекта: какие окна, какие объекты на них, к каким тегам ПЛК привязаны.
- Пополнить память примеров: вынуть картинки, тексты, типовые окна («механизм»: заголовок, переключатели, уставки).
- Собрать проект по образцу: взять пример как шаблон, скопировать окна и объекты, поменять тексты, теги, имена
  окон, сдвинуть объекты.

## Как запускать

Синхронизатор ставит папку в `%SYSAI_HOME%\tools\ebpro-cmtp` и запускает `python server.py` на своём Python
(нужна только cryptography — она у синхронизатора уже есть, ничего не скачивается). Доступ к папкам проверяет SYSAI.

Разбор примера: `cmtp_info` → `cmtp_windows` → `cmtp_objects` (по окну) → `cmtp_tags`; картинки — `cmtp_extract_images`.
Сборка по образцу: `cmtp_edit` со списком правок → новый файл; исходник не меняется. Номера окон — из `cmtp_windows`
(`number`), номера объектов — из `cmtp_objects` (`index`); после копий смотри их заново.

## Объекты окна (cmtp_objects)

- `index` — порядок в окне (на него ссылаются правки), `kind` — вид: Window (рамка окна, всегда первый), Text, Picture,
  BitLamp, SetBit, ToggleSwitch, NumericInput, NumericDisplay, FunctionKey, ASCII, QRCode, Rect, Line; со знаком «?» —
  вид угадан; `part_XX` — вид ещё не опознан.
- `bbox` — рамка [лево, верх, право, низ] в пикселях окна; `labels` — подписи (текст, шрифт, размер, x, y);
  `texts` — прочие тексты объекта.
- `addresses` — адреса: slot 1 — чтение, 2 — запись, 3 — доп. (видимость и т. п.), 0 — прочие адреса внутри объекта;
  у тегов OPC UA — `tag` (имя) и `node`. Пустые и «0» не показываются.

## Правки (cmtp_edit)

`edits` — список, выполняется по порядку; если одна правка не прошла — файл не пишется.

- `{"op": "text", "window": "Нория 3", "old": "Нория 3", "new": "Нория 11"}` — любой длины; если новый текст
  длиннее, рамка объекта «Текст» расширяется вправо по ширине символов (сужения нет). `object` — только в этом объекте.
- `{"op": "move", "window": "Нория 3", "object": 5, "dx": 150, "dy": 0}` — рамка и подписи внутри неё
  (те же байты, что меняет сам EasyBuilder при перетаскивании).
- `{"op": "tag", "window": "Нория 3", "old": "VariablesRetain.OFF_DKS_3", "new": "VariablesRetain.OFF_DKS_11"}` —
  перепривязать объекты окна на другой тег OPC UA: тег должен быть в таблице проекта (`cmtp_tags`) и того же типа.
- `{"op": "rename_window", "window": "Нория 3", "new": "Нория 11"}` — имя окна в списке окон.
- `{"op": "clone_window", "window": "Нория 3", "new": "Нория 11", "number": 91}` — копия окна со всеми объектами
  (теги, тексты, картинки — как в исходном) под новым номером и именем; без `number` — следующий за последним окном,
  без `new` — то же имя. Копия получает новый GUID, как при копировании в самом EasyBuilder. Дальше правки этого
  же списка могут обращаться к копии по номеру (`"window": "91"`) — по имени, если оно не совпадает с исходным.
- `{"op": "clone_object", "window": "Нория 3", "object": 35, "to": "Нория 11", "dx": 0, "dy": 60}` — копия объекта
  (вид, теги, подписи) в конец списка объектов того же окна или окна `to`, со сдвигом; номер копии — в ответе.
  Окно-рамку (index 0) не копирует — для этого `clone_window`.

## Ошибки

- «payload not 16-byte aligned» / «truncated payload» — файл повреждён или это не проект EasyBuilder.
- «no window …» — нет окна с таким именем или номером: посмотри `cmtp_windows`.
- «text … not found» / «tag … is not used» — в окне нет такого текста или тега: посмотри `cmtp_objects`.
- «is not in the OPC UA tag table» / «type mismatch» — нового тега нет в проекте или у него другой тип.
- `cmtp_relabel` требует новый текст той же длины (для текстов любой длины — `cmtp_edit`, op text).
- Копии: в архиве MFC каждый объект занимает номер, вставка сдвигает ссылки на классы дальше по файлу — инструмент
  пересчитывает их и сверяет итог; при любом расхождении правка отменяется, файл не пишется:
  - «window number … is taken» / «window numbers go from 3 to 1999» / «no free slot» — номер занят или вне
    диапазона: свободные номера — пропуски в `cmtp_windows`.
  - «cannot be placed reliably; take N» — пустые номера перед новым окном не отличить от конца предыдущего окна:
    возьми предложенный номер N (сразу за предыдущим окном) или номер в другом пропуске.
  - «not every object is recognised» — в окне есть объект, который разбор пропустил; копировать и вставлять в такое
    окно небезопасно.
  - «holds sub-objects» / «defines class» — у объекта вложенные объекты (группа, тренд и т. п.) или в нём описан
    особый класс: такие пока не копируются, возьми похожий объект из другого окна.
  - «class numbering does not add up» / «class references do not add up» — файл устроен не так, как ожидалось:
    правка отменена, пришли проект разработчику.
  - «has no frame to shift» — у объекта не найдена рамка: копируй без dx/dy.
