# Распознавание речи: замеры (спринт 5)

Набор: 6 синтетических «совещаний» (5 сотрудников, один синтезированный голос с разной высотой для каждого
человека, шум помещения, эхо, гул 50 Гц), 274 слова. Генератор: `scripts/make_speech_testset.py`,
замеры: `scripts/speech_benchmark.py`. Модели не детерминированы: значения ниже — среднее нескольких прогонов.

| Конфигурация | WER | Говорящие названы по имени | Цена за прогон (~4 мин аудио) |
|---|---|---|---|
| Было: gpt-4o-transcribe, как в проде | 9,7 % | — | — |
| gpt-4o-transcribe + весь новый конвейер | 8,9 % | 41 % | $0,023 |
| **Gemini 2.5 Flash + весь новый конвейер** | **2,9 %** | 62 % | $0,012 |
| **Gemini 2.5 Pro + весь новый конвейер** | **1,5 %** | 84 % | $0,086 |

Другие модели (только слова, новый конвейер): gpt-4o-mini-transcribe 13 %, whisper-large-v3 24 %,
whisper-1 6 %. Deepgram Nova-3 и Yandex SpeechKit через OpenRouter недоступны — для их сравнения нужны
отдельные ключи.

Что дал каждый шаг на gpt-4o-transcribe (3 прогона): подсказка имён и терминов + исправление по справочнику:
10,1 % → 7,7 %; мягкое шумоподавление: 7,7 % → 7,1 %. Агрессивная очистка (loudnorm, dynaudnorm, сильный
afftdn) ухудшала распознавание до 12–14 %, поэтому оставлено только мягкое шумоподавление.

Определение говорящих при правильном разделении голосов (эталонные реплики): 15 из 16 (94 %); не назван
один человек, которого в разговоре никто не назвал и который не представился. Основная потеря в полном
конвейере — склейка похожих голосов моделью; синтетические голоса похожи сильнее, чем голоса реальных людей.
Голосовые профили сотрудников (уже есть в справочнике) снимают эту проблему.
