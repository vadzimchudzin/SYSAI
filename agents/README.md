# agents/ — то, что ставится на ПК сотрудника

Будет здесь (этап 6 и дальше, docs/opo/TASKS.md):

- `sync/` — синхронизатор: меняет код подключения на токен (хранит его в Windows Credential Manager), забирает
  подписанные доступы (`/agents/api/config`), проверяет подпись, применяет настройки Hermes и перезапускает агента,
  держит навыки SYSAI_Hub в папке только для чтения, отправляет предложения навыков, шлёт пульс.
- `installer/` — установка одной командой: Hermes, профиль `opo-<логин>`, синхронизатор, MCP-серверы.
- `plc-kit/` — MCP: разбор чертежей ТО (сначала Excel и PDF), теги с источниками, генерация, проверки.
- `machine-expert/`, `cad/` — MCP для EcoStruxure Machine Expert и чертежей (DWG/DXF).

Каждый MCP-сервер сверяется с подписанным файлом доступов сам (`access.json`), даже если обвязку заменят.
