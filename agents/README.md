# agents/ — то, что ставится на ПК сотрудника

Есть (этап 6, docs/opo/TASKS.md, docs/opo/NET.md — «Агент на ПК»):

- `installer/install.ps1` — установка одной строкой со страницы агента в SYSAI:
  `$env:SYSAI_CODE='КОД'; irm <SYSAI>/agents/api/install.ps1 | iex`. Ставит uv, синхронизатор, Hermes (если его
  нет), профиль Hermes по имени агента без встроенных навыков, первую синхронизацию, окно «Агент SYSAI» с ярлыком на
  рабочем столе и фоновую синхронизацию — при входе в Windows.
  SYSAI отдаёт его с подставленными адресом и версией (`app/net/installer.py`).
- `sync/` — синхронизатор `sysai-agent` (Python ≥ 3.11; на ПК — Python 3.12 от uv): меняет код подключения на токен
  (хранит его в Windows Credential Manager), забирает подписанные доступы (`/agents/api/config`), проверяет подпись,
  применяет настройки Hermes и `SOUL.md` и перезапускает шлюз Hermes, держит навыки и инструменты SYSAI_Hub в папках
  только для чтения, отправляет предложения навыков, шлёт пульс. MCP-серверы хаба запускает под охраной доступов
  (`sysai-agent mcp <имя>`), каждое действие самого Hermes проверяет хуком (`sysai-agent hook`), обновляется сам до
  версии, подписанной SYSAI, ставит и обновляет окно агента (`sysai-agent desktop`). Подробно —
  [sync/README.md](sync/README.md).
- `desktop/` — окно «Агент SYSAI» (Electron): разговор с агентом с видимыми действиями, просмотр файлов, проводник
  ПК и Хранилище SYSAI; агент показывает в нём файлы и открывает программы в пределах доступов. Подробно —
  [desktop/README.md](desktop/README.md).

Инструменты хаба для проекта «под ключ» (`hub/seed/`, [docs/opo/NEW_PROJECT.md](../docs/opo/NEW_PROJECT.md)):
`plc-kit` (программа на ST, связь, этапы), `machine-expert` (проект `.project`, компиляция, контроллер),
`ebpro-cmtp` (экраны), `pic-index` (картинки), `doc-kit` (документация).

Будет:

- `plc-kit` — разбор чертежей ТО (сначала Excel и PDF), теги с источниками.
- `cad/` — MCP для чертежей (DWG/DXF).

Они приходят на ПК инструментами SYSAI_Hub, не установщиком. Каждый MCP-сервер сверяется с подписанным файлом
доступов сам (`access.json`), даже если обвязку заменят.
